HTTP request–response timing: non-persistent, parallel, persistent and pipelined

Every TCP connection starts with SYN and SYN-ACK; the browser then sends the HTTP GET with the third handshake segment, and the server returns the object. The running total on the right adds the DNS lookup, each RTT and each object's transmission time.

Defaults reproduce the Kurose problem in Chapter2-Problems: DNS RTTs 4 + 44 + 8 = 56 ms, RTT_HTTP = 20 ms, 3 small objects.
